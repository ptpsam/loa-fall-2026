## Projects

### 1. SQL Practice

Practical exercises focused on learning SQL and working with PostgreSQL.

Topics covered:
- Filtering, sorting, and selecting data

**Technologies**: SQL, PostgreSQL

### 2. Tennis Club REST API

A backend application for managing a tennis club, built with Java and Spring Boot.

Current features:
- Court management
- User management
- Reservation management
- Input validation
- Centralized exception handling
- REST endpoints for creating, retrieving, updating, and deleting resources where implemented
- Automated controller tests

**Technologies**: Java, Spring Boot, Spring Data JPA, PostgreSQL, Maven, JUnit, Git

## Getting Started

### Prerequisites

- Java 
- PostgreSQL
- Git

### Run the API locally

1. Clone the repository.
2. Create a PostgreSQL database for the application.
3. Configure the database connection in your local application.properties file, using application.properties.example as a reference.
4. From the API directory, run:
`.\mvnw.cmd spring-boot:run`
5. Run the automated tests with:
`.\mvnw.cmd test`

Database credentials should remain local and must not be committed to Git.
